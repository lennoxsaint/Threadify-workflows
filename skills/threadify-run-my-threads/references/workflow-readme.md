# Run My Threads

"I don't write posts anymore. I approve them."

Use the complete [installable skill](../../skills/threadify-run-my-threads/SKILL.md).

Set it up once: connect Threadify, confirm your account and timezone, and let your agent create one daily schedule (05:30 local by default). Every morning the agent asks Threadify for up to five posts, fits them into open slots on your calendar, and shows them in the agent thread. Reply "yes" from your phone and they are scheduled exactly as shown; reply "skip 2" or "no" to change that.

Threadify writes the posts with Claude Opus 5.5 when your plan allows it, Gemini as fallback. Your agent never rewrites them. The only change it may make is lowercasing (keeping names, brands and places), and a bundled guard script proves that for every post before you see it.

Most always-on agents run on a pile of schedules, burn tokens and do very little. Run My Threads runs once a day, never touches posts already on your calendar, never publishes immediately, and reports what each run used when your agent's host shows it. A scheduled post is not a published post.
