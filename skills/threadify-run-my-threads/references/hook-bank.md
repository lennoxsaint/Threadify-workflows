# Source-backed hook templates

This reference describes mechanics, not a substitute bank of proven examples.

For each slot, read the actual source post in full. Save its URL, text, recorded performance and observation date privately. Extract a template with placeholders, then fill it with the creator's relevant information. Save the adaptation beside the template. Use a number only if it really happened.

Search own greatest hits, My Vault and optional connected Viral Vault. A title, snippet, generic example or unverified claim of virality is insufficient. If no suitable source is available, hold the affected slot. Keep the other slots moving.

Mechanisms can include a withheld cause, unexpected result, story interruption or a specific reveal. Choose from actual observed source mechanics; do not assert these labels prove performance. Do not copy third-party wording, personal facts or identity. Each slot needs a different mechanism, angle and proof assignment.
