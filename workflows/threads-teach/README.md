# Threads Teach

Use the installable skill `threadify-threads-teach`; its `SKILL.md` holds the full instructions.

This workflow teaches a creator to write for Threads in ten short lessons built on Lennox Saint's core frameworks. It keeps a private workspace with the learner's mission, lessons and learning records, so each session continues from the last. With a Threadify connection it teaches on the learner's own posts and results; without one it works on pasted posts and says what it cannot see.

Every lesson ends with one post the learner writes themselves. The workflow coaches and does not write that post for them. Saving it as a draft and scheduling it are separate actions, each needing exact approval. A connection never grants that approval, and a scheduled post is not a published post.

The lessons cover the core frameworks and say plainly where they stop. The workflow does not promise growth.

The teaching method is adapted from Matt Pocock's [`teach` skill](https://github.com/mattpocock/skills/tree/main/skills/productivity/teach) under the MIT License; the notice ships with the skill in `references/ATTRIBUTION.md`. His original pairs well with this one for any other subject.
