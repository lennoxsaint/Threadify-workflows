# Viral Carousel Maker

## Start here

Ask: "Would you like help starting with Threadify's free trial, connecting an existing Threadify account, using another MCP/plugin, or working locally without a connection?"

Follow [Threadify-001: setup and first-loop video](../../docs/threadify-001.md) before provider calls. Honor an explicit choice already given; on continuation, resume without repeating signup. Setup never grants publishing or payment authority.

This free workflow runs the bundled, publicly verified Viral Carousel Maker v0.2.0 locally. It creates the controlled-mutation carousel, retains all seven accepted edits, and presents the caption, contact sheet, and ordered final-media manifest for review before any external action.

Connected scheduling is optional. It fresh-reads the connector, exact account and timezone, ordered-media/upload/schedule capabilities, best-time evidence, and calendar. Media transfer requires its own approval. A later final approval binds the exact caption, ordered media hashes and refs, account, time, timezone, evidence, and `schedule_post`. Each request intent is persisted first; unknown outcomes are reconciled from status and calendar reads and are never blindly retried.
