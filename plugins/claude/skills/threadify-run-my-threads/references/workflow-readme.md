# Run My Threads

Prepare five daily posts from a deterministic weekly plan, using actual successful source posts and distinct evidence. Threadify writes initial drafts; the assistant applies only explicit owner-requested edits. No mandatory editorial audit or automatic regeneration loop.

Short hooks are one sentence; listicles go straight into the list. Thread openings are three sentences with two loops and a final colon. New thread parts target 22–48 words. All facts and refreshed metrics require evidence.

Private state records source/template/adaptation, generation attempts, exact revisions and approval hashes. Missing sources hold only affected slots. Ambiguous timeouts reconcile saved drafts before Gemini fallback. Approval binds the latest account, text and times. Scheduling retains calendar, idempotency and readback checks.

See the canonical skill and its state-and-recovery reference. Personal settings, source bodies and drafts stay outside the public repository. Optional external vault connectors remain optional.
