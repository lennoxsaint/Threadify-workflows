# Attribution

## Teaching method

The way this skill teaches is adapted from the `teach` skill by Matt Pocock:

https://github.com/mattpocock/skills/tree/main/skills/productivity/teach

Adapted from it: a teaching workspace that keeps state between sessions, a mission that grounds every lesson, short lessons that each end in one tangible win, retrieval practice and spacing, learning records that decide what to teach next, a glossary that grows as the learner does, and a notes file for teaching preferences. The file formats in [workspace formats](workspace-formats.md) follow the shape of his mission, learning record and glossary formats, rewritten for Threads.

Changed here: the subject is fixed to Threads, lessons come from a set curriculum instead of open research, lessons read the learner's own posts, lessons are plain text files, and each lesson ends with a post and an approval-gated save or schedule.

If you want to learn any other subject this way, use his original. It pairs well with this skill.

Matt Pocock did not write, review or endorse this skill.

## Threads frameworks

The framework notes in `frameworks/` are Lennox Saint's own teaching, written for this skill. The worked examples are his real public posts from @lennox_saint, quoted exactly, with the publish date and the view count at the time the lesson was written. The two short reply and comment exchanges in lessons 8 and 9 are made up and marked as such, because other people's comments are not quoted here.
