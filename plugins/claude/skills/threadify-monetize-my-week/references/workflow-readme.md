# Monetize My Week

Use the complete [installable skill](../../skills/threadify-monetize-my-week/SKILL.md).

This workflow selects seven eligible existing drafts for one saved offer, leaves every post body unchanged, prepares tailored tracked Auto Plugs, and schedules only after exact campaign approval. It does not generate a new week or promise sales.

Connected operation requires current draft, offer, Calendar, timing, scheduling and attribution tools. When those capabilities or Auto Plug entitlement are unavailable, retain a local review packet with the exact gap and manual alternative. A schedule is not publication, and attribution is not causation.
