# AI Content Forensics attribution

The public workflow generalizes the method first published in
[`lennoxsaint/ai-content-forensics`](https://github.com/lennoxsaint/ai-content-forensics),
copyright Lenny Saint and released under the MIT License.

Threadify Workflows reimplements the portable contracts: bounded corpus intake,
deduplication, platform-aware comparisons, evidence-to-claim traceability,
constitutions, insight auditing, an opinionated thread, and optional local
visuals. It does not include upstream hardcoded creator names, private corpora,
machine paths, dates, hooks, or background watchers.
