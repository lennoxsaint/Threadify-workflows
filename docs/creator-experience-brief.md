# Creator plugin experience brief

## Audience and job

Individual Threads creators need a repeatable path from credible source material to a daily batch they can review, revise and schedule deliberately. The public method and local engine are MIT; the shared corpus, proprietary ranking, Brain and hosted service remain in Threadify.

## Public entry points

| Skill | Trigger | Finished result | Boundary |
| --- | --- | --- | --- |
| Vault Setup | Build a useful starter inspiration library | Selected-source preview, approved saves with exact readback or honest local/disconnected coverage | Not a bulk migration or copying license |
| Create My Day | Prepare today's content | One reviewed batch of 1–5 exact drafts with sources, gaps and proposed times | No implicit scheduling or publication |
| Create My Week | Plan seven days | Seven-day blueprint; rolling Day 1 drafts by default or upfront drafts by choice | Later evidence and approval remain necessary |
| Create My Month | Plan four weeks | Explicit 28-day blueprint with resumable daily reviews | Not a calendar-month or guaranteed-growth promise |

Continue My Plan belongs to the Day skill and the common protocol; it is not a competing fifth default workflow. Qualified Buyer Research, X cross-posting/articles, Brain Sync and YouTube editing remain advanced. Audience signals, transcript seeds and carousels are later candidates. Exclude personal voice packs, private founder operations, legacy engagement bots and immediate publishing.

## Dependencies and host capabilities

Threadify is optional for host-authored local drafting from supplied sources and facts. It is required for real shared-Viral/Brain/analytics access, editable hosted drafts, validation and scheduling. Actual entitlement determines availability; the plugin must not invent it.

| Host capability | Disposition | Use |
| --- | --- | --- |
| read, list, search, grep | preferred | Discover the installed bundle and existing private plan state |
| write, patch | mutation | User-scoped drafts and private state only |
| shell | mutation | Run the local engine and validation; no implicit external authority |
| python | not_needed | The small deterministic kernel uses Node 18+ |

The earlier packaging brief proposed a canonical host-workspace-operator skill.
That skill and the recorded Autopilot package are unavailable in the current
tooling, so neither is bundled. The installed plugin-creator specification does
not declare that dependency. Keep the Autopilot-specific packaging check pending
until its canonical source is available; do not invent a replacement skill or
claim that check passed.

The four creator bundles run their local engine independently in isolated tests.
They require host-provided filesystem access and Node 18+, not a bundled Python
executor. Canonical logic remains in lib/creator with generated copies checked
for parity. Filesystem access is not a permission grant from this plugin, and
isolated CLI tests do not prove that an installed host loaded the skills.

## Discovery and listing

Three starter directions: Vault Setup, Create My Day, Plan My Content. Direct discovery cases name these jobs. Indirect cases include “I have five good source posts; help me turn them into a reviewable day” and “I need a four-week plan without drafting everything now.” Negative cases include bulk corpus export, copying an unlicensed post verbatim, publishing without review, automatic public replies and a request unrelated to creator content.

Keep execution triggers narrow. Read and draft preparation may be suggested from clear creator intent; imports, feedback sends, reminders and schedules each retain their separate approval. The listing can promise preparation and review controls only after the final packaged skills pass installation and scenario checks. No shipped, live or growth claim follows from local tests.

The brand mark should express selected source cards becoming a clear daily sequence. Reuse verified Threadify identity rather than generic AI sparkles. Final light/dark assets and publisher/legal/support details still require the packaging and submission gates.
