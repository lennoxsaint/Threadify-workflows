# Public skill disposition audit

## Primary creator workflows

- Viral Vault Setup: guided source selection, disclosure, approval and readback.
- Create My Day: adjustable one-to-five-post pack, five by default.
- Create My Week: seven-day blueprint and rolling or upfront drafts.
- Create My Month: 28 days, labeled four weeks, with the same daily controls.

The portable private-reference mechanics were compiled into the public Node
engine: source rights/provenance, deterministic templates, freshness, review
binding, private state, recovery and retry controls. Personal account/timezone
locks, the fixed follower experiment and the external swipe dependency are not
part of the public creator engine.

## Preserved advanced or compatibility workflows

- Qualified Buyer Research: bounded qualification and offer-free reply staging;
  never Send. Its existing standalone installer/update source is preserved.
- X cross-posting: source-status checks and an X-ready artifact, not live X proof.
- X Article: draft article packet from approved material, not publication.
- Brain Sync: approved atomic memory changes and readback.
- YouTube editing: separate Eddy engine dependency; unavailable engine means
  no finished-edit claim. Promotion is separately reviewed and approved.
- Daily Posts Heartbeat: delivery of already-approved copy, not a competing
  creator planner.
- Weekly Winner Replication and Daily Greatest Hits: retained workflow IDs and
  reusable source/scheduling mechanics; core creator skills own default planning.

Root advanced bundles retain existing skill names and local references.
The QBR proposal test now checks propagation into both standalone and root
bundles. Full-source filesystem install, upgrade from v0.4.1 and rollback pass
in isolated test directories; actual Codex loading and final-artifact proof
remain separate gates.

The YouTube manifest now makes Threadify tools optional for edit-only use.
Promotion instructions separate local review, approved external media upload,
final scheduling approval and opt-in feedback sharing. The source-level checks
do not prove an Eddy edit or a live promotion. The archive excludes the Eddy
submodule; initialize it only in an appropriate source checkout or use a
separately verified installation/finished launch kit.

## Later candidates

Audience signals, transcript seeds and carousel production remain outside the
core release. Cross-platform execution, automatic public replies, bulk migration
and media production are not core creator features.

## Excluded material

Do not bundle Lennox voice packs, private CRM/founder operations, raw meeting or
Readwise bodies, legacy engagement bots, immediate publishing, retired-brand
ghostwriting, private Brain state, proprietary corpus or hosted ranking logic.
Customer voice and offers come from that customer's verified context.

This is a source/disposition audit, not a completed archive privacy review.
Revalidate the final extracted archive and its exact inventory before release.
